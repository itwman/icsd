# قالب فایل seed آزمون هر دوره

هر فایل یک ماژول پایتون با یک متغیر `QUIZ` (dict). نام فایل = همان نام فایل دوره (مثلاً python_basics.py).

```python
QUIZ = {
    "course_slug": "python-basics",          # باید با slug دوره یکی باشد
    "title": "آزمون پایانی پایتون",
    "pass_percent": 70,
    "time_limit_minutes": 20,
    "questions_per_attempt": 0,             # اختیاری؛ ۰ یعنی همه‌ی سؤال‌ها، مثلاً ۲۰ از بانک ۳۰تایی
    "questions": [
        {
            "text": "متن سؤال (فارسی، واضح، یک مفهوم)",
            "explanation": "توضیح کوتاه پاسخ درست — بعد از آزمون نمایش داده می‌شود",
            "choices": [
                {"text": "گزینه‌ی درست", "correct": True},
                {"text": "گزینه‌ی نادرست", "correct": False},
                {"text": "گزینه‌ی نادرست", "correct": False},
                {"text": "گزینه‌ی نادرست", "correct": False},
            ],
        },
    ],
}
```

## قواعد
- دست‌کم ۱۵ سؤال برای هر دوره (دوره‌های بزرگ: بانک ۳۰ سؤالی با questions_per_attempt = 20)، هر سؤال ۴ گزینه، فقط یک گزینه‌ی درست.
- سؤال‌ها باید از محتوای همان دوره (فایل seed/courses/<name>.py) بیرون بیایند و همه‌ی فصل‌ها را پوشش دهند، از ساده به دشوار.
- کد داخل متن سؤال یا گزینه با بک‌تیک: `print(x)`. بدون HTML.
- گزینه‌ی درست را در موقعیت‌های مختلف بگذارید (نه همیشه اول).
- متن فارسی روان؛ اصطلاحات فنی لاتین می‌مانند.
